# STT Benchmark Lab Implementation Plan

> For agentic workers: execute inline using superpowers:executing-plans, with one independent review after implementation.

**Goal:** Implement an honest, durable local research workbench and native inference components, preserving explicit hardware validation gates.

**Architecture:** FastAPI/SQLite coordinator plus independent subprocess worker. React browser UI and a shared Swift Apple package. Versioned manifests and immutable experiment snapshots connect the components.

**Tech Stack:** Python 3.12, FastAPI, SQLite, FFmpeg, React, TypeScript, Vite, TanStack Table, SwiftUI, WhisperKit, FluidAudio.

**Spec:** `docs/architecture.md`, plus the user's master build specification.

## Global constraints

- Only owner recordings in project evaluation; synthetic test fixtures stay isolated in temporary directories.
- No fabricated results, remote iPhone inference or unverified compatibility claims.
- Preserve original audio, raw predictions, historical references and failure evidence.
- Existing checkout is already isolated: do not create a Git worktree.
- External model downloads and all Apple validation require available platform/network prerequisites.

## Review focus

- Unicode mixed scripts: preserve meaningful Turkish and Arabic distinctions.
- Concurrent reference edits: conflict rather than overwrite verified work.
- Interrupted inference: retain attempts and reclaim leases without duplicate outputs.
- Blind review: no names, metrics, timing or stable family order before lock.
- Partial assets/device disconnections: never classify invalid or missing outputs as success.
